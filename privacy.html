ホームプライバシーポリシー利用規約

プライバシーポリシー

本ポリシーは個人開発アプリ「AI-Company」に適用されます。

取得するデータ

利用者の同意したGoogle APIの権限に応じて、YouTubeのチャンネル・動画情報、Google Driveのファイル情報・コンテンツなどを取得することがあります。認証時に許可された範囲を超えてアクセスしません。

利用目的

コンテンツ制作、動画管理・投稿、ファイルの保存・整理、運用上の動作確認を自動化するために使用します。

保存と共有

認証に必要なトークンは自動化環境のシークレット管理機能などに保管し、公開Webサイトには掲載しません。取得したGoogleユーザーデータを広告目的で販売しません。サービス運用に必要な処理基盤への取扱いを除き、本人の許可なく第三者に提供しません。

保持と削除

目的に必要な期間のみ情報を保持し、不要になったデータや連携情報は削除します。利用者はGoogleアカウントの接続管理でアクセス権限を取り消せます。保存済み情報の削除依頼は下記問い合わせ先にご連絡ください。

安全管理

認証情報のアクセス制御と権限の最小化に努めます。Google APIから取得した情報の利用は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

改訂

アプリの機能変更に応じて本ポリシーを更新することがあります。
